# Sitewide Visual Direction

The homepage established the approved navy, cream, white, blue, and gold art direction. For issue #86, the current rendered homepage is the visual source of truth for the sitewide theme cleanup. That direction now applies across public pages, including service hubs, service-area pages, service detail pages, quote pages, and utility pages.

Use the design-system tokens, primitive variants, page patterns, and shared utilities in `DESIGN_SYSTEM.md` to carry the theme forward. Do not recreate the homepage look with page-local hex values, raw inverse color utilities, one-off shadows, one-off gradients, duplicated CTA class overrides, or copied decorative panels.

The current system includes illustrated brand artwork, water-wave rhythm, claim-safe trust bands, image-led service cards, city-context media, branded CTA panels, and restrained legal/confirmation pages that still share the site chrome and typography.

Headings, copy, links, and calls to action remain responsive HTML. Completed-result photos are independent examples and must not be described as matched before-and-after proof unless a verified project record supports that relationship.
